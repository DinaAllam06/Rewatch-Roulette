# 🎲 Rewatch Roulette

A Python web application that helps users decide what TV episode to watch by randomly recommending episodes from popular shows.

Users can select a show and shuffle a random episode, making it perfect for rewatching sitcoms or avoiding the “what should we watch?” problem.

---

## 🚀 Features

- Shuffle a random episode from a selected TV show
- Multiple shows supported
- Episode data stored in a structured JSON directory
- Simple and fast user interface
- Built with a Python Flask backend

---

## 🛠 Tech Stack

- **Python**
- **Flask**
- **HTML/CSS**
- **JSON data storage**
